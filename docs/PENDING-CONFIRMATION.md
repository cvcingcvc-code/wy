## 更新方式

1. 在 GitHub 网页或云端智能体中编辑 `src/config/site.ts` 与双语内容文件。
2. 产品事实变化时同时更新 `src/content/zh.ts` 与 `src/content/en.ts` 的 `products`，保持阶段标签与边界一致。
3. 提交后等待 GitHub Actions 通过；Pages preview 会自动更新。
4. 确认无误后再合并到 `main`。

不要在未确认时填入邮箱、电话、地址、客户名单、融资金额、性能数字或“行业领先”等无法证明的表述。
